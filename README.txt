TORNEO INFANTIL — PROTOTIPO FINAL NAVEGABLE

Abrir index.html en un navegador.

Características del prototipo:
- Navegación real entre vistas HTML mediante href.
- Crear y editar se realiza en ventanas emergentes dentro del módulo actual.
- Antes de guardar o actualizar aparece una segunda ventana de revisión con el resumen de los datos y las opciones Regresar / Guardar.
- Eliminar se mantiene únicamente como opción de evaluación del prototipo y siempre exige confirmación.
- Equipo incluye color identificador estable.
- Jugador incluye posición deportiva.
- Jornada agrupa partidos; Partido relaciona dos equipos; los marcadores se plantean como cálculo a partir de los goles registrados.
- Goles e incidencias se relacionan con un partido.
- Tarjeta roja muestra y exige fecha de suspensión.
- CSS y JavaScript están centralizados en assets/.
- La lógica JavaScript está organizada con clases para mantener responsabilidades separadas.

Este paquete es un prototipo visual estático. No sustituye la implementación Yii 2 ni la base de datos.
